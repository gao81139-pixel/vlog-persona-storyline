# Vlog Persona Storyline（Vlog 人设叙事）

一个将普通日常转化为真实、可拍摄Vlog叙事的 Codex Skill。它不把“流水账”一概删除，而是将真实时间线作为可信底座，再通过有动机的预期差和可见结果，让观众从行为中感受到稳定的人物特质。

## 核心模型

`真实的常识事件 ＋ 有动机的反常选择 ＋ 可见结果／反思 → 可被观众感知的人设印象`

这是一套创作与测试框架，不是“必爆公式”。

## 它会做什么

- 每个新任务先完成固定十问，收集目标、受众、真实日程、人设证据、资源和边界。
- 从真实时间线中识别观众的正常预期与创作者的实际选择。
- 检查反常选择是否具有真实动机、合理代价和可见结果。
- 设计日常基线、触发情境、选择、过程、结果和反思的完整节拍。
- 输出候选叙事线、开场钩子、镜头清单、旁白提示、人设证据图和发布测试方案。
- 排除危险挑战、过量饮酒、道路冲突、骚扰、假人设、伪造结果和未经同意的拍摄。

## 安装

将仓库克隆到个人 Codex Skills 目录：

```powershell
git clone https://github.com/gao81139-pixel/vlog-persona-storyline.git "$env:USERPROFILE\.codex\skills\vlog-persona-storyline"
```

本机创建版本已经安装到 `$CODEX_HOME/skills/vlog-persona-storyline`。

## 使用

```text
使用 $vlog-persona-storyline 为我的账号设计一条真实、可拍摄的Vlog人设叙事。
```

第一次响应会先提出十个问题；收到回答后才会生成方案。

## 来源与改进

本 Skill 根据用户提供的视频进行方法抽象。它保留“常识事件、反常行为、人设形成”的核心结构，但把“反常行为”限定为真实、有动机、可承担后果的选择，并补充事实、同意、隐私、安全、商业披露和效果验证要求。视频原文件不包含在仓库中。
